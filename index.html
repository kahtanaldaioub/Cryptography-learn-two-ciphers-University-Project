How do secret messages work?

Learn with two ciphers: an old letter-shifting method and the AES standard used today. Try them, see each step, and compare what makes them different.

Project by Kahtan Aldaioub, Kahtan Zaioud, Ali Ismail, and Mohamed Ahmed

What you will learn

  • See how a key changes a message into ciphertext.
  • Follow Vigenère letter by letter and AES one step at a time.
  • Explain why an old cipher is easy to break and why real encryption needs careful implementation.

Cipher When How it works Key idea Learning point
Vigenère cipher 16th century Shifts letters one at a time Repeating word Patterns can reveal the message
AES-128 Modern standard Transforms 16-byte blocks in 10 rounds 128-bit key Safe use also needs sound key handling and authentication

Important safety note

These examples are for learning, not for protecting real messages. Vigenère is breakable. This AES demo uses CBC, which does not detect tampering, and its text key handling is simplified. Use a trusted cryptography library in real applications.
