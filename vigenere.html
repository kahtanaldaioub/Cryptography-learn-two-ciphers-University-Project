Vigenère: shift letters with a key

A hands-on lesson in a historical cipher. Change the message or keyword and watch each letter move.

The idea in one sentence

Each message letter moves forward in the alphabet by an amount chosen by the matching letter of a repeating keyword.

Follow these steps

  1. Choose a message and a key

    For example, the message is ATTACK AT DAWN and the key is LEMON.

  2. Repeat the key over the letters

    Ignore spaces when matching letters: ATTACKATDAWN / LEMONLEMONLE.

  3. Turn key letters into shifts

    A means shift 0, B means 1, and so on. L shifts 11 places; E shifts 4.

  4. Shift each message letter

    The first A shifts by 11 to L. The result is LXFOPVEFRNHR. Spaces and punctuation stay as they are.

Try an experiment

  • Encrypt ATTACK AT DAWN with LEMON. Then change the key and compare the result.
  • Encrypt a message with repeated letters. Do those letters always become the same ciphertext letter?

Why is it not secure today?

The key repeats, so patterns in the message can show up in the ciphertext. Historical methods such as frequency analysis can recover the key and message. Vigenère is useful for learning, but it should not protect real information.
