AES-128: modern block encryption

Explore how AES changes a message in blocks, then step through the first block's ten rounds.

The idea in one sentence

AES repeatedly transforms 16 bytes at a time using a secret key, producing ciphertext that looks unrelated to the original message.

What happens when you encrypt?

  1. Turn text into bytes

    The message is encoded as bytes, split into 16-byte blocks, and padded if the last block is short.

  2. Start with a random IV

    CBC mode combines each block with the previous ciphertext block before AES encrypts it. The first block uses a random starting value called an IV.

  3. Run ten rounds

    Each round substitutes bytes, shifts rows, mixes columns, and adds a round key. The final round skips the column-mixing step.

  4. Return the IV and ciphertext

    The result is shown in hexadecimal. It starts with the IV, followed by the encrypted blocks. A fresh IV makes repeated encryptions look different.

Try an experiment

  • Encrypt the same message twice with the same key. The hex results should differ because each run gets a new IV.
  • Use the slider to inspect each step. The highlighted squares show bytes that changed from the previous step.

Important limits of this demo

This educational AES-CBC example does not authenticate data, so it cannot detect tampering. Its text key is simply cut off or zero-padded to 16 bytes; real applications need a password-based key derivation function and authenticated encryption.
